### 6. LIME (Explainable AI) from Scratch


# LIME from Scratch for Skin Cancer Detection

## Overview
This project implements LIME (Local Interpretable Model-agnostic Explanations) from scratch and applies it to a skin cancer detection model based on ResNet18.

## Objectives
- Understand explainable AI techniques
- Implement LIME without external libraries
- Interpret CNN predictions

## Features
- Custom LIME implementation
- Integration with ResNet18
- Visualization of feature importance

## Tech Stack
- Python
- PyTorch
- NumPy
- OpenCV / Matplotlib

## Dataset
- Skin cancer dataset (e.g., ISIC)

## Results
- Generates interpretable explanations for predictions
